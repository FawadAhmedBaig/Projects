# Metricool Shorts CSV Exporter

A Chrome Extension that streamlines the process of scheduling YouTube Shorts via Metricool. It integrates directly into Google Drive, allowing you to select a folder of videos and instantly generate a formatted CSV file ready for bulk import into Metricool.

## ✨ Key Features

- **Google Drive Integration**: Injects a floating UI panel directly onto Google Drive folder pages.
- **Metricool Template Formatting**: Automatically generates CSVs matching Metricool's exact format requirements, with fields pre-populated for YouTube Shorts.
- **Customizable Scheduling**: Set a starting date, time, and posting interval right from the extension's UI to spread out your scheduled posts automatically.
- **Automatic Permission Updates**: Automatically updates video permissions in Google Drive to "Anyone with the link" so Metricool can successfully fetch the video files.
- **CSV Chunking**: Splits large exports into multiple CSV files based on a customizable chunk size to avoid import limits.

## 🛠️ Tech Stack

- **Extension Framework**: Chrome Extension Manifest V3
- **Languages**: Vanilla JavaScript, HTML, CSS
- **APIs**: Google Drive API (v3), Chrome Identity API (OAuth2)


2. **Open Chrome Extensions**:
   - Go to `chrome://extensions/` in your Google Chrome browser.

3. **Enable Developer Mode**:
   - Toggle the **Developer mode** switch in the top right corner.

4. **Load Unpacked**:
   - Click the **Load unpacked** button in the top left.
   - Select the folder containing the project files (where `manifest.json` is located).

5. **Authenticate**:
   - Depending on the Google Cloud project setup linked in the `manifest.json` (`client_id`), you might need to authenticate your Google account when the extension first tries to access Google Drive.

## 💡 Usage

1. Navigate to a Google Drive folder containing your videos (`https://drive.google.com/drive/folders/...`).
2. Click the extension icon in your Chrome toolbar to toggle the floating panel.
3. In the floating Metricool CSV Exporter panel, configure your scheduling settings:
   - **Start date**: The date for your first scheduled post.
   - **Start time**: The time for your first scheduled post.
   - **Interval (minutes)**: Time gap between each subsequent post.
   - **Max rows per CSV**: Splits the export into chunks if you have many videos.
4. Click **Export Shorts → CSV**.
5. The extension will scan the folder for videos, update their permissions, and automatically download the formatted CSV file(s) to your computer.
6. Import the CSV into Metricool for bulk scheduling!

## ⚠️ Notes

- The extension only works on Google Drive folder URLs.
- It specifically looks for files with the MIME type containing `video/`.
- Ensure your Google Cloud OAuth Client ID is properly configured if you are setting this up from scratch, as the current `client_id` in `manifest.json` might be restricted to specific test users or environments.
