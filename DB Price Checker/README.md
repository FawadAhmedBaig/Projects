# DB Price Checker

**DB Price Checker** is a Chrome extension that seamlessly converts any fiat currency into the $DICKBUTT memecoin on any webpage you visit. 

## Features
- **Real-time Conversion**: Automatically detects fiat prices on web pages and converts them to $DICKBUTT using live data from the CoinGecko API.
- **Widespread Currency Support**: Automatically detects and supports a wide variety of fiat currencies including USD, EUR, GBP, JPY, CNY, CAD, AUD, and many more based on symbols, page context, locale, or meta tags.
- **Smart DOM Parsing**: Intelligently scans page content (including dynamic elements) for price patterns while ignoring non-visible or irrelevant HTML tags.
- **Custom Integrations**: Special handling for complex price structures on popular sites like Amazon, eBay, and Airbnb to ensure accurate display.
- **Dickbutt Mode**: An optional "memecoin only" mode that replaces the original fiat price entirely with the $DICKBUTT equivalent. When turned off, it displays the memecoin price alongside the original fiat price.
- **Easy Toggle**: Easily toggle the extension ON/OFF directly from the extension popup, with a clear badge indicator on the extension icon.

## Installation

Since this extension is not currently published on the Chrome Web Store, you can install it manually:

1. Download or clone this repository to your local machine.
2. Open Google Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** by toggling the switch in the top right corner.
4. Click on the **Load unpacked** button in the top left corner.
5. Select the `DB Price Checker` project folder.
6. The extension is now installed and active!

## Usage

- Once installed, the extension runs automatically in the background.
- Browse to any e-commerce site or webpage displaying prices (e.g., Amazon, eBay, Airbnb).
- You will see the fiat prices automatically augmented or replaced with their $DICKBUTT equivalents.
- Click on the extension icon in the Chrome toolbar to open the popup. From here, you can toggle the extension on/off or toggle the **Dickbutt Mode**.
