# Tailwind CSS Newsletter Card Design

A simple, responsive, and aesthetically pleasing Newsletter Subscription Card designed using HTML and [Tailwind CSS v4](https://tailwindcss.com/).

## 🚀 Features

- **Responsive Design:** Adapts smoothly across different screen sizes.
- **Modern UI:** Utilizes Tailwind CSS utility classes for a sleek look, including linear gradients and rounded corners.
- **Fast Build:** Powered by [Vite](https://vitejs.dev/) for an extremely fast development server and build process.
- **Tailwind v4:** Uses the latest `@tailwindcss/cli` for styling.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS (v4)
- Vite (Dev Server)

## 📦 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository (or download the project folder).
2. Navigate to the project directory:
   ```bash
   cd "TailwindCSS Newletter Card Design"
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

To start the Vite development server, run:

```bash
npm start
```

This will open the project in your default web browser (typically at `http://localhost:5173`).

## 📁 Project Structure

- `index.html`: The main HTML file containing the structure of the newsletter card.
- `style.css`: The input CSS file (if you want to add custom CSS alongside Tailwind).
- `output.css`: The generated Tailwind CSS file containing the utility classes used in the project.
- `package.json`: Contains project metadata, scripts, and dependencies.
